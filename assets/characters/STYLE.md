# Bayper 角色画风基准

当前基准：`bayper.pixel.maid10` 的像素表达修订版（2026-10-26）。用户已明确认可 [凛新版像素母版](rin/source/master-pixel-v2.png)，要求同步原设计约束。此图是当前画风的有效视觉参考；第二轮10号保留紧凑二次元头身与造型方向的来源，不再以细密抖色或平滑插画效果指导新素材。

## 跨角色、服装与动作的固定要求

- 2D女性拟人角色，保留紧凑二次元头身比例；不同角色的发色、眼睛、耳尾、服饰不照抄凛。
- 实际桌面尺寸下能辨认方形像素簇、阶梯轮廓与清晰色块。轮廓、五官、头发和衣褶采用一致的逻辑像素网格，不以高清插画叠纹理或CSS滤镜代替。
- 减少平滑渐变、柔化边缘与密集抖色；以少量明暗层次组织材质，优先脸与识别特征的可读性。有限色板与每材质约三档明暗是制作起点，不声称生成图片已严格通过32色计数。
- 凛新版提示词使用128×192逻辑画布、约100×150角色主体作为制作目标；具体导出网格必须由切帧与实际渲染检查确认，不能只按提示词推定达标。
- 桌面角色本体的默认视觉占用以约128×128 pt为目标（2026-10-26用户附图确认的理想大小）；这是本体的视觉包围范围，不是要求把角色拉伸成正方形。保持原头身与宽高比，按比例适配该范围；场景若存在，其尺寸另算。透明画布、场景与交互命中区域分别定义，不把画布尺寸当角色本体大小，也不让额外空白抢占鼠标。源帧可保留256×384等制作尺寸，macOS点与Retina物理像素区分。主窗口角色详情预览可放大，不能反向当作桌面尺寸。此前128×192 CSS点仅是早期画布试样，不能作为当前本体尺寸规范。当前桌面按已接入动作的共同可见范围统一缩放，主体验收上限128pt；凛坐下/静坐使用同一比例，坐姿不重新放大，详[休息运行验收](../../.hapilon/polaris/Bayper完整交付/s07-rest-runtime-review.md)。
- 同角色换装、表情和动作保持脸、体型、发型骨架、耳尾位置与核心识别点；服装细节、发丝、像素密度不得在各帧随机变化。对齐脚锚、统一缩放，检查循环接缝与深浅背景透明边缘。

## 验收与迁移

用户认可的是新版静态画风，不等于全部动画或所有角色已验收。凛旧master-v1/idle-v3/wave-v2、琥珀和澄旧素材保留制作追溯。当前桌面基础素材与凛休息动作已按各自验收记录迁移；睡眠、倾听等候选尚需正式触发与衔接验收，不能只改文档声称全库完成。正式管理页面中凛的形象引用统一到master-pixel-v2；原型历史插图保留追溯，不反向覆盖正式形象。角色的development-candidate标识及内容发布约束仍有效。

所有新素材任务引用本文件及当前母版。Codex负责生图与审查，Claude Code负责切帧、对齐、播放和程序接线。原始提示词、源图、导出和验收证据分别保留，动画候选不自动提升为已发布资源。
