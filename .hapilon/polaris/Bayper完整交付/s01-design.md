# S01 首次相遇业务设计

Codex 受托冻结 v1，2026-10-25。范围来源：PRD 首次相遇、模型配置、独立运行；先交付真实首次流程，后续切片补桌面动画与其它页面。

1. 首次启动仅展示模型配置：Base URL、模型名、API Key，说明一次连通检查将发送固定无个人信息的短请求。输入有效且服务返回有效助手文本后才保存并进入许愿。失败保留可编辑内容，不创建关系、不假称已连接。
2. 默认 HTTPS；用户自行配置本机服务时允许 loopback HTTP，其他明文地址拒绝。Key 不写日志、不回传 renderer、不写明文数据库；使用 Electron safeStorage，安全存储不可用时报错，不默默降级。
3. 许愿仅按版本角色已写好的特征做本地排序，空愿望允许使用默认顺序。不会额外调用模型，不把愿望写成长期偏好。展示候选性格与推荐原因，可查看其他候选或改愿望；未确认不接纳。
4. 确认接纳用一个持久化事务创建关系、初始数值（10/100/0）、默认固定位置、当日实际名单和当前角色。重复点击不会多次接纳或重复创建。重新启动直接恢复已接纳角色，无需重新许愿。
5. 仅完成模型配置尚未接纳时，重启回到许愿。已经接纳后网络不可用仍进入小窝，不清空关系或强退；真实聊天在后续切片接入。
6. 此切片角色资料使用明确标记的开发候选；正式资源完成前不能通过 S07 或总交付。首个窗口沿用原型视觉语言，正式数据由主进程 SQLite 提供，原型 localStorage 不迁入。

状态：未配置→已验证配置/未接纳→已接纳。无 Herdr、无外部目录访问也完整可走通。后续设置变更不要求重新接纳。
