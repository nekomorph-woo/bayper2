# S03f R4：纯否定翻转与独立不确定分句

## 先保留的失败（当前源，未修）

`pre-fix-failure.log`：

- 已有 `用户喜欢热茶`，用户“请纠正一下，我不喜欢热茶。”：回复“我还不确定你指的是哪一件事…”，未改库。原因是新对象词准入把纯否定翻转挡住，且目标定位先删掉了唯一话题词“热茶”。
- 已有 `用户喜欢茶`，用户“请纠正一下，可能，我喜欢咖啡，不是茶。”：回复“好，这条记忆已按你给的原话更新为‘我喜欢咖啡，不是茶’…”，独立“可能”未进入正文，trust 被保存为 stated。

## 最小修复

1. 删除 `positiveTokensOf(anchor) 必须含旧正文之外新词` 的准入；改为只要求锚点含**实质内容 token**（排除纯否定/系词、时间词、不确定词），因此纯极性纠正可以通过，纯“不是茶”或孤立“可能”仍不会变成事实。
2. `resolveTarget` 只移除相对旧事实**新增**的对象词；旧对象词（如“热茶”）保留为目标依据，纯否定翻转可定位。
3. 若本轮原话存在不确定分句，而本次正文没有包含该不确定词，则不落库，返回“这句话里有不确定的表达…你能确认一下具体意思吗？”；不把独立“可能”提升为 stated。
4. 保留完整正向内容/否定上下文；未新增谓词表、同义词表或解析器。
