## 未验证 / 明确边界

- 构造 HTTP 只证明本地授权、检索、事务与上下文过滤；不证明真实 DeepSeek 语义识别。真实模型和 GUI 尚未验证。
- broad 检索仍依赖分词/字面命中；完全无共同字词的同义指代可能检索不到候选，此时如实不处理。
- 纠正新内容必须是用户原话中的完整安全分句；命令与新内容挤在同一分句时可能要求最小澄清，而不是由模型切分改写。
- 仅支持“今天/今晚”的可验证当日时效；其他过去/未来/模糊时间统一最小澄清，不擅自定天数。
- 临时理解使用现有 `remember/correct` 与 `.current.<条目ID>` factKey，不新增表或引擎；用户本轮明确分句以 `explicitConsent` 建立新来源，旧来源仍被排除。不同 factKey 的同义事实整合仍未覆盖。
- 现有 trust 枚举只有 `stated/inferred`；用户带“可能”的说法以 `inferred` 保存且保留原词。
- 删除命令来源按当前角色永久排除，聊天原文保留但不再进入该角色的模型上下文。
- 未覆盖：明确转告、仅当前角色保留的分享范围、全局自动分享禁令、不同 factKey 同义事实整合；既有本地选中管理入口未在 GUI 复验。
- 源摘要见 `source.sha256`；未新增 tools 目录。
