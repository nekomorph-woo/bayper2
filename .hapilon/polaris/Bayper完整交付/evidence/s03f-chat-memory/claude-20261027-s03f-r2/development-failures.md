# r2 返修过程失败摘录

以下为返修过程中实际观察到的开发自测失败，保留原始结论；最终源码与日志见同目录。

## 第一次运行（14/16）

- POL-CHATMEM-001 today：期望 `expiredMessages` 不含“时效:有效至”，实际为 true。原因是断言把 systemPrompt 里的说明文字算进了记忆上下文；改为只检查第二条 system message。
- POL-CHATMEM-004 unique：期望“唯一条目不是目标证据”返回歧义，实际执行了删除。原因是目标匹配的汉字二元片段把“帮我忘记”里的“我忘”当成候选依据；增加 Non-topic 字符过滤后修复。

## 收紧请求框架后（13/16）

- `本轮候选列表没有找到 所有记忆`
- `本轮候选列表没有找到 住址`
- `管理回合应发送有预算的候选`（actual null）

原因：忘记/删除动词正则把可选礼貌前缀“帮我”吃进匹配，而请求框架只检查匹配位置之前，导致“能帮我忘记…”未被识别为管理命令、未构建候选。改为动词正则不吞礼貌前缀，由请求框架/赤裸命令检查决定后修复。
