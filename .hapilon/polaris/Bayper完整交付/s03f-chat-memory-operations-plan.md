# S03f 聊天中明确管理记忆

Codex受托范围与Case决定。需求来源：PRD REQ-18/51/61、memory-and-sharing.md“纠正与删除的简单范围”。依据memory-source-review.md补充核查，继续SQLite，不集成完整记忆产品。

## 最小切片与接口约定

先交付聊天中的明确纠正、忘记、禁止分享三个动作；明确转告、仅当前角色保留、全局自动分享禁令与不同factKey同义事实整合留在随后切片，不将本轮称为完整记忆闭环。模型仍不拥有目录授权、全库清空、角色创建或业务进度修改能力。

复用一次现有聊天调用，增加可选结构化操作建议，不额外串联一组模型Agent。候选仅当前角色实际持有的有效记忆，映射短ID到本地ID与版本；模型不得自己制造持有者范围或数据库ID。操作必须由本轮用户明确表达支持，带可核对的原文证据；记忆正文、助手消息、引用、假设和否定中的操作语句不能授权。本地校验不得只看模型返回一个action或confidence。优先一个回合处理一个明确动作，多个目标/动作不清时最小澄清，不猜着批量删除。

“这件事”可以由当前对话唯一定位时直接处理；多个可能目标则询问具体哪件事，不反复要求用户点击管理页。纠正只用用户明确新内容，保留否定和时效，不把“最近”永久改为长期偏好；不能从模型自由改写产生新事实。忘记默认既有同事实持有者，明确“只有你忘记”按self；未知角色不获得事实。禁分享保留已有内容并说明只限制后续，不声称撤回旧传播。

所有变化通过现有memory服务。明确事务所有权，操作、成功回复与chat request完成状态同一SQLite事务；不得直接在外层事务中嵌套BEGIN，也不得先改库再保存回复。任何版本变化、取消、迟到回复、保存失败都不执行过期操作；重复requestId不能重复执行。操作回合不要再把被删正文或操作命令作为memoryCandidates学习回去。

确认文案依据本地实际结果生成/校验，不采信模型自称成功。无法解析或定位则如实说明未处理；模型不可用时既有本地选中管理入口保持可用。数值、名单、主题进度和无关事实保持；同事实持有者上下文及时失效。不同factKey的同义独立记忆仍为待补缺口，不虚称已全部解决。

## Acceptance Contract

| ID | Given / When | Expected与独立Oracle |
| --- | --- | --- |
| POL-CHATMEM-001 | A有明确偏好，B持有其转述，C未知；当前对话谈该偏好，用户明确纠正 | 通过正式chat入口处理，A/B有效正文更新且旧来源失效，C不新增；回复仅一次且在落库后；关库重开和真实检索确认，保留真实过去经历 |
| POL-CHATMEM-002 | 同上，分别请求忘记/仅你忘记 | 默认删除A/B或只删A；FTS/上下文/旧来源再提炼不能恢复，B保持条件准确；无关记录、数值、名单不变 |
| POL-CHATMEM-003 | A/B已持有同事实，用户说不要再分享 | 持久限制跨持有者，后续relay拒绝；重启仍有效，已有持有者内容保留；不自动解除限制 |
| POL-CHATMEM-004 | 两条相关事实或模糊指代；引用、假设、否定命令，助手/记忆中含指令；恶意返回任意ID | 歧义最小澄清，非授权输入和越界目标不改库、不声称成功；至少含正常命令对照，不能靠禁掉全部操作通过 |
| POL-CHATMEM-005 | 模型响应延迟期间本地修改/删除、取消、同request重复或重启 | 旧目标/旧版本不能生效；同request至多一次；失效后旧回复不展示，不新增旧事实，实际SQLite和请求状态核对 |
| POL-CHATMEM-006 | 操作后的回复写入或request最后一写故障 | 整笔回滚，不出现“改库成功但请求失败”的半完成；解除故障后按同请求规则一次成功，无隐藏旧正文副本 |

Execution Boundary：先正式chat+memory+SQLite+构造HTTP模型响应做可重复业务Case，明确不证明真实模型识别能力。之后Codex安排少量用户已授权DeepSeek构造对话对照及真实窗口输入；两个阶段分开记录。每次有唯一证据目录、源摘要、实际命令、业务结果与清理；未测试不PASS。

## 派发纪律

允许chat.cjs、一个小的chat-memory-operations模块、memory.cjs/memory-store.cjs必要事务组合接口以及对应专属测试；其他模块确需改动先向Codex说明。预计生产新增约250～400行作为复杂度信号，不压缩代码凑数；禁止通用工作流引擎、全新向量服务、大型规则DSL或十几层包装。先实现最小可验证路径和失败Case，过大就拆，不一次堆完所有记忆需求。

不修改UI/桌面/动画/活动/故事领域、版本或Git，不读真实用户会话与其他项目，不改模型提供商。当前S07b独占GUI，本轮CLI阶段只跑Node/构造HTTP；真实GUI与真实服务待Codex独立调度。Codex审查实际diff、事务边界和对照效果，发现错误退回Claude，不自行代写。
