# 小窝、陪伴、活动与线索

状态：PRD讨论细化，2026-10-25。产品依据为 [PRD](prd.md)。用户已明确同屏最多1位、陪伴名单1固定位＋4随机位，以及名单成员共用预算的自动API资格；本文件中的其他调度、数值和交互细节是Codex建议，未实现或体验验证。

## 角色归属与位置

| 概念 | 数量与职责 |
| --- | --- |
| 已结识Bayper | 范围随版本提供的可结识角色扩展，用户确认接纳，长期保留身份与记忆 |
| 小窝 | 承载休息、玩耍与日常归属；不是让所有角色同时弹出桌面形象的窗口 |
| 当日陪伴名单 | 最多5位，1个可换人的固定安排＋4随机位；不重复占位、人数不足留空 |
| 当前同屏Bayper | 最多1位，从名单中产生，承接直接互动与当前可见表达 |
| 系统自动API资格 | 名单成员有资格，仍受状态、冷却、全局预算和并发限制 |

固定安排持续保留指定角色，并非始终占据同屏；随机位的刷新时刻、抽取公平性与用户临时换人规则待讨论。已结识、在名单、在同屏、正在探索是不同事实，不能用一个“在线”状态混在一起。

## 活动调度建议

流程为：**名单资格 → 当前状态/冷却 → 共享预算 → 机会抽取 → 活动 → 记录/线索/分享**。一次活动可以没有新线索，不能用“模型已回复”直接视作解锁成功。

- 自动角色请求全局最多1个在途，探索默认最多1位并行；调用并发和持续探索各自计数。
- 名单外角色不自动启动模型任务，局部休息/玩耍动画可用已有素材完成；不因为存在于小窝就不断抽API。
- 角色换出名单时停止产生新自动机会。已开始活动建议收尾或暂停而非反复重试；是否允许有界收尾、如何承接跨日任务待细化，不偷偷延长资格。
- 正在探索者不上屏扮演即时陪伴，回到可陪伴状态后再轮换。精力和心情可以影响活动意愿，不影响应用接收工作事件。
- 分享给不在名单的角色可以保存带来源的信息，不立即触发其模型回应或接力聊天；她获得资格后再决定是否表达，避免一次分享形成全员API链。
- 用户主动请求不参与随机抽取；与名单外角色聊天的入口和是否需要先换位仍待决定。
- 外部源分析同时满足目录授权与调用预算；不能借探索直接访问新目录，或另建无限的“整理后台”。
- 调用预算、并发、冷却、概率分别控制。模型故障、退出与恢复不补造成功记录，不一次性补跑全部离线机会。

本轮不冻结每小时额度、单次时长或概率公式，不实现调度器。

## 同屏互动与气泡

建议用户正在聊天、拖动或明确互动时延后自动换人；用户可以主动切换，但切换不把当前角色对话交给另一角色继续冒名回应。每位角色有自己的上下文与记忆，昵称仅作显示标识。

系统分享通常由当前同屏角色表达；其他成员产生的成果先排入各自活动记录，上场时再说，或以标明作者的留言呈现。留言的具体形式与顺序待设计，不能额外生成第二个直接互动角色。

必需通知与日常内容分开承担义务：Herdr真实变化不依赖模型措辞，不等候随机分享机会，不因角色累了、心情不好、聊天、探索或换人而静默取消。没有同屏角色时应用仍通知。气泡标明实际事件来源；转告者身份与Agent身份分开。

普通气泡至少4秒、P0至少6秒、动作默认1.5秒、默认N=3气泡等既有讨论参数保持，N不是角色数量。多气泡满额时的时效冲突、日常分享是否占同一队列或独立额度，仍须专门体验验证，不在此伪称已有硬保证。

## 角色故事线索与服装线索

- 合资格的探索与日常活动可少量带来故事片段、角色线索或服装线索；每次活动不保证命中，也不为已结识数量增多而同步增加总抽取次数。
- 线索有稳定归属与连续进度，重复内容合并。模型只能在角色设定、版本可用内容和已知进度内表达，不能编造角色已被接纳或服装已穿用。
- 角色线索指向尚未结识的已发布角色，可通过同伴引荐引出轻量相遇；用户接纳后进入小窝，不自动挤占固定安排、随机位或同屏位置。
- 服装线索指向某一角色的服装，关联主题故事；换装仍是同一位Bayper。服装解锁、获得与当前穿用分别看待，自动穿用规则待讨论。
- 没有已发布对应内容时可保留叙事线索，不虚称素材已可用。拒绝/暂缓相遇不惩罚，也不立即连续换人追问；冷却与重遇规则待细化。
- 有趣的探索分享与可改变解锁进度的线索分开，避免每次API闲聊都推进角色/服装发现。

## 角色独属记忆与共享

每位Bayper有与用户的独属记忆。真实共同活动按参与者记录，旁听或分享标为获知而非亲历；换位、回小窝、昵称或服装变化不重置记忆。

共享建议作为一次有来源的角色间活动：讲述者选取可分享的片段，接收者保留谁说的、何时获知、引用哪段有效理解。是否需要用户控制分享范围、哪些内容不主动分享待细化，不默认全员看到全部聊天。

用户纠正后，相关共享派生理解也需更新或失效；不能反复转述旧版本让误解生效。共享不复制原始目录读取权限，不触发名单外角色自动模型任务。具体记忆存储、引用与修正传播方案仍在研究。
