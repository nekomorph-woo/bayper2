# 原生桌面布局返工

2026-10-26，用户要求减少网页感，在单屏组织内容、减少滚动。本轮由 Codex 受托主持，OpenDesign MCP 显式 Claude Code 实现，仍以既有 PRD 为业务基线。

## 设计决定与首轮范围

保留暖灰与低饱和绿、系统字体、角色像素插图，重做窗口布局而非换色。先改小窝、角色详情、设置三个代表页面及必要共享样式，后续扩展故事和连接。默认1200×800、最低960×680。

- 固定左导航、紧凑标题工具栏、占满剩余高度的内容区。取消网页大标题、顶部大留白、纵向卡片堆叠、全页面滚动。
- 小窝：当前角色与陪伴操作构成主区域，右侧紧凑今日名单；见闻使用窄底部区域或可打开详情的列表，不把历史堆到页面下方。首屏直接完成聊天、换陪伴与查看名单。
- 角色：人物列表与详情分栏，概览/衣橱/记忆用分段控件；固定角色身份与主要动作，长记忆仅列表内部滚动。避免同时展开所有信息。
- 设置：设置分类列表＋当前表单，短标签、对齐控件、分组行和适量分隔线；不要宽大卡片和说明文长页。保留校验、错误、授权与删除边界。
- 聊天固定面板，消息局部滚动，输入框始终可见。详情使用 sheet/面板，不能一味新增弹窗。
- 允许真正长内容局部滚动，不通过缩小字号、裁掉内容、overflow:hidden掩盖不可达内容实现“一屏”。正文14px左右、辅助不低于12px。
- 保留现有交互与数据归属；不得用删功能降低复杂度。网页中的窗口灯仅示意，不能冒称原生OS组件。

## 验收

两种尺寸分别查看实际截图和尺寸溢出；三个代表页 document 不应发生垂直或水平滚动，必要局部区域独立。键盘焦点、Escape、聊天发送、角色切换、衣橱、记忆纠正、设置校验均复验。主操作在单屏可见。Codex实际审查后再延展，不以运行 succeeded 视为设计通过。
