# 原生窗口第二步

首轮三个代表页面已实际截图，Codex认为固定分栏方向符合用户要求，继续沿用，不能改回长页。

1. 延展 stories / connections：统一固定toolbar、侧栏和剩余高度workspace。故事用列表＋正文详情，邀请按钮在详情清楚可达；连接用来源/Agent列表与通知历史分区，来源与独立Agent身份清楚。长列表/正文局部滚动，不丢现有互动。
2. 小窝冗余：凛旁的固定位tag与最下方“固定位·正在桌面”重复，合并保留一处状态；顶部sub不要复述名单里已有内容。角色详情的关系数值可以保留，但标签/数值对齐，少用重复状态。
3. 模型设置目前“配置保存在本机，不发任何请求。Key需要填写，但只留在输入框里”等制作说明移入README，UI改为面向用户的简短说明；同时原型仍禁止真实API，不能更改实际模拟行为。避免暗示随意http都可用于生产，显示安全服务地址规范。侧栏“原型演示”制作说明同样移入交付说明。
4. 所有三个代表页及故事/连接在1200×800和960×680单屏，输入/主操作可达；聊天局部滚动、输入固定，维持Escape/焦点恢复。检查衣橱、记忆、所有设置分区、错误消息出现后不会被裁掉。

仅当前OpenDesign项目原型，不改bayper repo、不Git、不真实API、不凭据。代码仍Claude Code，沿用已有结构，最小修改，不引框架。报告实际做过的验证和未覆盖。Codex继续独立截图和走查。
