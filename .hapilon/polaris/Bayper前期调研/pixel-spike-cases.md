# 独立像素角色最小实测合同

2026-10-25。需求来源：用户授权按既定分工，Codex生成同一角色多视图及短循环，Claude Code切帧、对齐与播放，Codex审查并保留证据。不进入Bayper产品设计。本合同只约束技术样本，不定义产品角色或动作。

| ID | Given / When | Expected | Oracle / 执行边界 |
| --- | --- | --- | --- |
| PIX-01 | Codex内置imagegen生成四视图，再以该图为参考生成短动作 | 正/右/后/左可辨认，同角色灰蓝毛、奶油胸口、青绿眼、橙围巾；动作保持正视身份 | Codex实际审图，保留原图与提示词；不是用户审美确认 |
| PIX-02 | Claude Code读取真实PNG并切帧 | 实测alpha与背景；六帧无截断，统一尺度/画布与基线，不能每帧独立缩放；不能用空白帧或重复帧伪造 | 原图/输出尺寸、alpha、bbox、变换记录和接触图独立复核；无Mock |
| PIX-03 | 真实浏览器加载处理后PNG，在Canvas连续播放 | 可看到呼吸/眨眼、六帧时序和循环；暂停冻结、继续推进，单帧可审查，资源加载无报错 | 浏览器时间点帧状态/画面和实际操作；非仅HTTP或文件存在 |
| PIX-04 | Codex观看全部帧及循环首尾 | 身份一致，脚底稳定；检查头身/尾巴/饰物跳变、像素闪烁与接缝；有缺陷明确记录，不把播放器可用等同素材合格 | Codex视觉判断+度量，不冒充用户体验；没有外部视频模型或原生窗口实测 |
| PIX-05 | 完成实验 | 保留源图、处理代码、播放入口、规格与证据；停止自建临时服务 | Git差异与PID/端口记录；不触碰已有环境 |

实现切片：research/pixel-spike/，仅一个处理脚本与一个无构建依赖HTML播放器，素材放assets；代码由Claude Code实施。优先Pillow+标准库，无新框架/依赖安装，不增加通用引擎。目标约200–300行清楚代码，必要时说明理由而非挤行。若PNG没有真实透明或格子不规则，先报告，Codex决定返修路径，禁止暗中用相近毛色阈值抠图。

采样规模：四视图、六帧短动作、一个Canvas页面；本轮不比较PixiJS性能，不启动Electron/Tauri，不关联Herdr状态。技术判断由Codex按master授权执行，用户无需选择参数。
