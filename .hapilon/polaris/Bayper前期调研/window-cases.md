# Electron / Tauri 2 最小窗口实验合同

用户要求比较两套技术栈的窗口行为与资源占用；仅技术预研，不实现产品，不继续比较 Swift 或 Qt。Codex 按 master 授权确定实验边界、委派 Claude Code 编码并独立验收。

环境：本机 macOS 27.0.1；隔离根目录 /tmp/bayper-window-spike-ueR1x3。依赖、编译产物、浏览器数据与运行日志放入该目录；源码放 research/window-spike/。仅启动自有测试窗口，不连接 Herdr 或修改用户工作窗口。原生测试底板与只读观察器仅作独立测量工具，不是第三种候选技术栈。

两套使用相同 240×240 逻辑像素透明画布，中心 120×120 不透明色块；静止与约 30fps 单色块动画各一组，不加载网络、图片或业务功能。先测试框架标准 API，不预先引入第三方 panel 插件或原生补丁。每个开关记录实际应用结果，失败如实保留。

| ID | Given / When | Expected / Oracle |
| --- | --- | --- |
| WIN-01 | 同一棋盘测试底板上显示透明窗口 | 角落透出底板、中心色块不透明；截图与底板对照，不以 transparent=true 代替实际观察 |
| WIN-02 | 同一覆盖点，先接收点击再开启整窗穿透，实际鼠标点击 | 接收组底板计数不变；穿透组底板计数增加；保留两侧日志，不把程序调用事件处理函数当真实点击 |
| WIN-03 | 底板持有输入焦点，显示/隐藏再显示 overlay，以及点击 | 记录 frontmost PID、底板 keyWindow 与 overlay focus 事件；显示不应抢焦点；CUA 若自动激活目标 app，必须标注该混杂因素 |
| WIN-04 | overlay 开启跨工作区；切换普通 Space | 以实际切换与可见性证据判断；不能用配置值或窗口存在代替跨 Space 可见 |
| WIN-05 | 底板进入原生全屏 Space，再返回 | 实际确认 overlay 是否可见及焦点；仅拉伸/最大化不算全屏；必要时用失败对照或截图说明 |
| WIN-06 | 相同内容、尺寸与动画速度，单独运行候选，预热后采样 | 分别报告 idle/animation 的进程组 RSS 与区间 CPU；纳入 renderer/GPU/WebKit helper，无法完整归属时明示下界或不可直接比较；不测 debug/dev server 代表 release |
| WIN-07 | 结束实验 | 恢复自有全屏/Space操作，关闭自有窗口和进程；归档证据后清理临时依赖、产物与数据目录 |

资源结果是单机小样本，RSS 可能重复计算共享页，不是物理独占内存或电池结论。若缺少权限、无法可靠切换 Space 或无法归属系统 WebKit 进程，分别标 INCONCLUSIVE/NOT_COVERED，不伪造 PASS。不改系统权限或桌面偏好来凑通过。
